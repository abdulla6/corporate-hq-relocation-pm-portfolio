📖 DEFINITIONS & ACRONYMS — STUDY REFERENCE

PDM Node Fields

ESEarly Start — The earliest possible week the activity can begin based on predecessor constraints.
EFEarly Finish — ES + Duration. The earliest possible week the activity can end.
LSLate Start — The latest week the activity can begin without delaying the project end date.
LFLate Finish — LS + Duration. The latest week the activity can end without delaying the project.
DurDuration — The planned number of weeks to complete the activity.
FloatTotal Float (TF) — The amount of time an activity can be delayed without delaying the project. LF − EF or LS − ES.

Dependency Types

FSFinish-to-Start — The successor cannot start until the predecessor finishes. Most common relationship.
SSStart-to-Start — The successor can start after the predecessor has started (with optional lag). Allows parallel work.
LagA mandatory waiting period between the predecessor and successor. Example: SS+2 means start 2 weeks after the predecessor starts.

PERT Estimates

OOptimistic — Best-case duration if everything goes perfectly.
MMost Likely — Realistic duration under normal conditions.
PPessimistic — Worst-case duration if significant issues arise.
TePERT Expected Time — Weighted average: (O + 4M + P) ÷ 6. Used for probabilistic planning.
σStandard Deviation — Measure of uncertainty: (P − O) ÷ 6. Higher σ = more risk.
ZZ-Score — (Target − Te) ÷ σ. Used to calculate probability of hitting a deadline via normal distribution.

Project Management Terms

PDMPrecedence Diagramming Method — The network logic technique used to sequence activities with nodes and arrows.
WBSWork Breakdown Structure — Hierarchical decomposition of project deliverables (e.g., 1.1.1, 2.1.2).
CPCritical Path — The longest path through the network with zero float. Any delay here delays the project.
RAIDRisks, Assumptions, Issues, Dependencies — A project tracking log for governance and risk management.
RACIResponsible, Accountable, Consulted, Informed — A responsibility assignment matrix for roles.
UATUser Acceptance Testing — End-user validation of systems before go-live.

Domain-Specific Terms

MEPMechanical, Electrical, Plumbing — Building infrastructure systems installed during fit-out.
VoIPVoice over Internet Protocol — Telephony system using internet data rather than traditional phone lines.
RFQRequest for Quotation — Procurement document sent to vendors to obtain pricing.
SnagDefects or unfinished items identified during final inspection before handover.
HypercareIntensive on-site support period immediately after a major go-live or migration.

Roles & Titles

PMProject Manager — Leads planning, execution, and delivery of the project.
CFOChief Financial Officer — Senior executive responsible for financial operations and lease approval.
COOChief Operating Officer — Senior executive overseeing business operations and project closure.
HRHuman Resources — Department managing staff engagement, change management, and relocation.
ITInformation Technology — Department responsible for infrastructure, networks, and system migration.
